# 副本功能说明（INSTANCE）

## 配置结构

在 `configs.json` 里为每个账号添加 `zone4` 和 `instanceGlobal` 配置：

```json
{
  "1": {
    "zone4": [
      {
        "type": "INSTANCE",
        "enabled": true,
        "generalIds": [49215473],
        "instanceLevels": [1, 2, 3]
      }
    ],
    "instanceGlobal": {
      "coordinates": [
        [150, 30],
        [151, 30],
        [152, 30]
      ]
    }
  }
}
```

## 字段说明

### zone4 数组（编队配置）

- **type**: 必须是 `"INSTANCE"`
- **enabled**: `true` 启用，`false` 禁用
- **generalIds**: 武将 ID 列表（支持多将编队，如 `[49215473, 44485363]`）
- **instanceLevels**: 要打的副本等级列表，如 `[1, 2, 3]` 表示打 1-3 级副本

### instanceGlobal（全局配置）

- **coordinates**: 副本坐标列表 `[[x, y], ...]`
  - 副本在地图上有固定位置（不像山贼需要扫描全图）
  - 例如 `[150, 30]` 表示坐标 (150, 30)
  - 可以配置多个坐标，程序会按顺序扫描

## 运行逻辑

1. **每 15 秒**检查一次（与刷黄相同的节奏）
2. **找空闲编队**：武将必须是「待命」状态、有兵、有体力
3. **扫描副本**：按 `coordinates` 配置的坐标扫描（op 5442）
4. **匹配等级**：找到符合 `instanceLevels` 的副本就立刻出征（op 5412）
5. **去重**：900 秒内打过的副本不会重复打

## 与刷黄的区别

| 功能 | 刷黄（THIEF） | 副本（INSTANCE） |
|------|--------------|------------------|
| 配置位置 | zone3 | zone4 |
| 目标坐标 | 螺旋扫描全图 | 固定坐标列表 |
| 扫描 op | 5440 | 5442 |
| 出征 op | 5410 | 5412 |
| 响应解析 | 解析山贼响应 | 相同（复用） |

## 日志示例

```
[副本] 出征 → 1級副本 Lv1 坐标(150,30) | 呂時亮 体力100/100 兵199
[副本] ✓ 已出征，行军至 (150,30)
```

或无目标时：

```
[副本] 无符合等级[1, 2, 3]的副本（已打5）
```

## 前置条件

与刷黄相同：
1. 武将必须在「配兵列表」（ASSIGN_SOLDIER）里启用并打勾
2. 兵力 ≥1200（冲车 ≥200）
3. 体力 > 0

## 如何配置副本坐标

1. **手动游戏里查看**：进入副本界面，记下坐标（通常是固定的几个点）
2. **抓包获取**：类似 `刷新山贼.har`，抓取游戏的副本刷新请求，里面会有坐标
3. **默认坐标**：常见副本坐标在 150-160 / 30-40 范围（需实测确认）
