### 现有代码 `king_client.py:158-164`

```python

    """副本扫荡（op 5120）→ 返回应答包列表。
```

**结论**：
- ❌ **op 5120** 不在操作码总表里，可能是老版本或错误的
- ✅ **op 6450-6462** 才是真正的副本协议
- ✅ **op 5412** 不存在！那是出征打黄巾（op 5410 expedition）

### 需要补充的协议函数

```python
# op 6450: 查询副本组列表
def 查询副本组(client: KingClient, zhang: int) -> List[Dict]:
    payload = struct.pack(">h", zhang)  # short
    return client.send_ops_raw([(6450, payload)])

# op 6459: 开始打副本
def 开始副本(client: KingClient, fuben_id: int, box_choice: int) -> List[Dict]:
    # short + int + bool
    payload = struct.pack(">hib", fuben_id, 0, box_choice >= 0)
    return client.send_ops_raw([(6459, payload)])

# op 6460: 查询副本记录
def 查询副本记录(client: KingClient) -> List[Dict]:
    return client.send_ops_raw([(6460, b'')])

# op 6462: 查询副本结果
def 查询副本结果(client: KingClient) -> List[Dict]:
    return client.send_ops_raw([(6462, b'')])
```
