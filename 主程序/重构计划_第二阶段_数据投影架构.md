## 目标架构：单向数据流

```
┌──────────────────────────────────────────────────────┐
│ 协议层 (core/protocol/)                              │
│   解析武将列表(), 解析部队(), 解析伤兵() ...        │
│           ↓                                           │
│ 原子数据层 (BotSession._原子数据)                    │
│   _部队表, _伤兵表, _兵种名表, _武将原始A4          │
│           ↓                                           │
│ 投影层 (app/presenters.py)                           │
│   build_generals(), build_troops(), to_poll()        │
│           ↓                                           │
│ 前端 API (/api/bot/{id}/poll)                        │
│   实时计算，无缓存状态                               │
└──────────────────────────────────────────────────────┘
```

### 关键原则
1. **单一真相源**：原子数据（_部队表、_伤兵表）是唯一真相
2. **投影即计算**：前端视图（generals, troops）是实时计算的投影
3. **无状态缓存**：删除 self.generals、self.troops 缓存
4. **按需投影**：只在 to_poll() 时计算，不提前构建

### Step 3: 删除缓存状态 + 改为属性投影 ✓（已完成）
**核心修改**：将 `self.generals` 和 `self.troops` 从实例变量改为 `@property`

**修改前**（当前）：
```python
class BotSession:
    def __init__(self):
        self.generals = []  # 缓存状态
        self.troops = []    # 缓存状态
        
    def _刷新武将(self):
        raw = 解析武将列表(dd)
        gens = self._建武将(raw, ...)
        self.generals = gens  # ← 手动更新缓存
        self.troops = self._建部队(gens, ...)  # ← 手动更新缓存
```

**修改后**（目标）：
```python
class BotSession:
    def __init__(self):
        self._武将原始A4 = []  # 原子数据
        # 删除 self.generals = []
        # 删除 self.troops = []
        
    @property
    def generals(self):
        """实时投影：_武将原始A4 × _部队表 → 前端武将结构"""
        from app.presenters import build_generals
        return build_generals(self._武将原始A4, self._部队表, self._兵种名表)
    
    @property
    def troops(self):
        """实时投影：_伤兵表 → 前端部队结构"""
        from app.presenters import build_troops
        return build_troops(self._伤兵表, self._兵种名表)
        
    def _刷新武将(self):
        raw = 解析武将列表(dd)
        self._武将原始A4 = raw  # ← 只更新原子数据
        # 删除 self.generals = gens
        # 删除 self.troops = ...
        return True
```

**影响范围**（需要修改的方法）：
1. `__init__()` - 删除 `self.generals = []`, `self.troops = []`
2. `_刷新武将()` - 只更新 `self._武将原始A4`
3. 登录流程 - 只更新原子数据
4. 删除 `_同步部队到前端()` - 不再需要手动同步
5. 删除 `_建武将()` 和 `_建部队()` - 合并到 @property
